# Logo

| File | Use |
| --- | --- |
| `ferrobasic-light.svg` | Wordmark for light backgrounds; the top of the root `README.md` |
| `ferrobasic-dark.svg` | Wordmark for dark backgrounds; the root `README.md` in a dark theme |
| `ferrobasic-icon.svg` | The mark alone, square, for small spaces; kept for the project website, which does not exist yet |

## Typeface

The wordmark is set in [Figtree](https://github.com/erikdkennedy/figtree)
by Erik Kennedy, licensed under the SIL Open Font License 1.1, from the
variable font `Figtree[wght].ttf` in
[google/fonts](https://github.com/google/fonts/tree/main/ofl/figtree):

- "Ferro" at weight 600 (SemiBold), letter spacing -28 units (-2.8% of the em);
- "BASIC" at weight 700 (Bold), letter spacing +15 units (+1.5% of the em);
- cap height 38.94, baseline at y = 68, "Ferro" starting at x = 122.29, and
  a gap of 9 between the two words.

The letters are converted to outlines, so the font does not need to be
installed to display the files; the OFL does not apply to artwork made
with the font. The mark (the "F" in the square) is drawn by hand and uses
no font.
